# Practice exam report outline

This is an original rehearsal layout, not an official OffSec template. Use
only after an authorized practice run. Before a real exam, follow the live
[OSCP+ exam guide](https://help.offsec.com/hc/en-us/articles/360040165632-OSCP-Exam-Guide)
and the exam control panel. Keep real exam data and proof outside public Git.

## Executive summary

Scope, objectives, total observed results, and limitations in plain language.

## Method and environment

Authorized scope, test window, starting access, tools/versions, and evidence
handling. Note any restricted tool use and the chosen target privately.

## Target 1: <label>

### Service discovery

Exact commands, relevant output, and interpretation.

### Initial access

Precondition → finding → command/request → result → independent verification.

### Privilege escalation

Starting identity → misconfiguration → action → elevated identity → evidence.

### Proof and screenshots

Record original proof-file location and target IP in the required interactive
shell screenshot, following current rules. Do not publish proof contents.

### Remediation

Concrete fix and verification method.

Repeat the same structure for all independent targets and each AD set member.
Keep the target order consistent with the exam control panel.

## Appendix

Tool versions, changed exploit excerpts where required, source URLs, and
supporting non-sensitive evidence. Review the whole PDF before submission.
