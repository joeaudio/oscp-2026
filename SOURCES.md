# Sources and limits

Checked 17 November 2026. External sources may change; recheck before the exam.
This repo paraphrases concepts and contains original exercises, not OffSec
course chapters, lab answers or copied third-party notes.

- [OffSec OSCP+ body of knowledge](https://help.offsec.com/hc/en-us/articles/38543335188756-OSCP-Body-of-knowledge): topic coverage.
- [PEN-200 syllabus](https://manage.offsec.com/app/uploads/2026/03/PEN-200_Syllabus.pdf): broader course themes.
- [OSCP+ exam guide](https://help.offsec.com/hc/en-us/articles/360040165632-OSCP-Exam-Guide): format, proof, report and tool rules.
- [AI usage policy](https://help.offsec.com/hc/en-us/articles/35549468971156-AI-Usage-Policy-in-OffSec-Exams): LLMs prohibited during OSCP+ exams.
- [Scaled scoring FAQ](https://help.offsec.com/hc/en-us/articles/54589877508884-OSCP-Equated-Scaled-Scoring-FAQ): December 2026 scoring change.
- [Nmap reference guide](https://nmap.org/book/man.html), [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/), [PortSwigger Web Security Academy](https://portswigger.net/web-security): technical practice references.
- [Microsoft Learn: Active Directory](https://learn.microsoft.com/en-us/windows-server/identity/ad-ds/get-started/virtual-dc/active-directory-domain-services-overview), [MITRE ATT&CK](https://attack.mitre.org/): AD terminology and technique descriptions.
- [Python standard library](https://docs.python.org/3/library/http.server.html): local lab runtime.

Exercises that require a real Linux/Windows/AD target give an authorized-lab
procedure instead of claiming this repo includes those environments. No
unverified lab completion or exam readiness is recorded here.
