# Evidence-based readiness check

Use this after each practice day. A reading session is **not demonstrated**
skill. Record results only from your own unaided work in ignored
`private/daily-log.md`; do not publish targets, credentials, proof files or
course-lab solutions.

| Skill | Demonstrated when... | Your evidence |
| --- | --- | --- |
| Enumeration | You identify services, test one lead, and reject one false lead without a walkthrough | Private target note |
| Web | You map requests and prove one issue with a before/after pair | Local miniweb or authorized lab report |
| Linux privilege escalation | You explain permission boundary and independently verify higher privilege | Authorized lab note |
| Windows privilege escalation | You verify service/task right and elevated context | Authorized lab note |
| AD | You map a credential-to-host path and confirm each edge | Authorized lab note |
| Pivot | You draw both tunnel legs and verify a loopback listener | Authorized lab note |
| Reporting | Another reader could reproduce each claim from commands, output and screenshots | Draft PDF |
| Time management | You finish a timed attempt and reserve report time without hints | Private daily log |

If no suitable Linux/Windows/AD lab is available, mark those rows **not
demonstrated**. Synthetic fixtures test reasoning, not full exploitation.
Do not turn the table into a guessed pass probability. Before scheduling or
taking an exam, read the current [exam guide](https://help.offsec.com/hc/en-us/articles/360040165632-OSCP-Exam-Guide).
